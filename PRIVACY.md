# Privacidade

Humanize BR é um plugin somente de skill. Ele não roda servidor externo, não exige conta e não coleta, armazena ou vende dados pessoais.

O texto que você envia é processado pelo agente de IA onde você usa a skill (Claude Code, ChatGPT, Codex ou outro compatível). Esse processamento segue os termos de privacidade daquele produto, não os deste repositório.

Visitar o repositório no GitHub pode gerar os registros normais de servidor e análise de acesso sob a política do próprio GitHub.

Dúvidas: abra uma [issue](https://github.com/Esl1h/humanize-br/issues).
